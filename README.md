# 🍵 Moss & Matcha

A cozy, responsive website for a fictional matcha brand.
Built with plain HTML, CSS, and JavaScript — no frameworks.

 **Live site:** https://safiakhan43.github.io/mossandmatcha/
---
## What it is

A one-page website for a small-batch matcha brand. Warm colors, soft animations, and a calm feel — like a slow morning with a bowl of matcha.
---

## Features

- Responsive (mobile + desktop)
- Smooth scroll navigation
- Animated hero with floating shapes
- Product cards with hover details
- Image gallery with hover zoom
- Fade-in animations on scroll
- Mobile hamburger menu
- Contact form

---

## Built with

- HTML
- CSS
- JavaScript
- Google Fonts

## How to run it

1. Download or clone the repo
2. Open `index.html` in your browser
3. Done
